Strategy — the four layers

L1 · Unit

Deterministic logic — parsing, taxonomy, facets, embed-text stability. No network, no DB. Runs on every push (GitHub Actions).

L2 · Integration

The seams — DB-backed tests (local Postgres), RLS user isolation. Opt-in, planned with the preference feed.

L3 · End-to-end

Browser-driven smoke flows (Playwright / webapp-testing). Planned with the web tasks.

L4 · Evals

AI quality is scored, not asserted: embedding benchmark (precision@5 + golden queries), retrieval eval, prompt benchmark (promptfoo grid). Regression gates for model/prompt changes.
